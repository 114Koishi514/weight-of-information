Encoding artwork slot
Place your original animation here. Recommended 640 x 320 or 800 x 400,
transparent or ink-green background. WebM, MP4, GIF, static PNG or SVG.
Set PTS.config.ASSETS.encoding in dist/config.js, for example:
{ src: 'assets/user-animation/encoding/sequence.webm', type: 'video',
  poster: 'assets/user-animation/encoding/still.png' }
Use type 'image' for a still, 'gif' for an animated GIF.
Relative paths start at dist/. Registration proceeds with or without the asset.
