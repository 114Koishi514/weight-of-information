PTS XP desktop artwork

The supplied images are in dist/assets/desktop. The five illustrated shortcuts use the same artwork in the Start menu. The About PTS icon is live text using the bundled IBM Plex Mono. The original cube logo sits on the green Start button with a transparent background and the full blue wallpaper is the desktop background.

To replace an illustration, change its relative path in PTS.config.ASSETS.icons in dist/config.js. Image keys are transmission, reception, computer, guide and record. ASSETS.wallpaper controls the background image. Keep transparent margins reasonably tight so the image remains legible at the desktop icon size.
